# GWMD 公文编辑器

用纯文本标记语言编写党政机关公文，实时预览 A4 排版效果，一键导出符合《党政机关公文格式》（GB/T 9704-2012）的 Word 文档（.docx）。

## 功能特性

- **纯文本编辑**：左侧编辑区编写 GWMD 文本，右侧实时预览 A4 公文效果
- **标准排版**：导出 docx 遵循 GB/T 9704-2012 —— A4 纸、版心 156×225mm（上 3.7 / 下 3.5 / 左 2.8 / 右 2.6 cm）
- **固定行模型**：正文仿宋 3 号、行距 29 磅、每面 22 行、每行 28 字，预览与导出使用同一套确定性分页模型
- **要素齐全**：版头（红头、发文字号、密级、紧急程度、份号、签发人、红线）、主体（标题、主送机关、正文、附件说明、落款、成文日期、印章、附注）、版记（抄送、印发机关和日期）
- **行内格式**：加粗、斜体、脚注（导出为 Word 页面底部真脚注）、超链接
- **自动编号**：标题四级自动编号（一、→（一）→ 1. →（1）），支持手工编号识别与接续
- **格式校验**：缺标题、未知指令、层级跳跃、脚注无定义等问题在预览顶部提示
- **表格 / 列表 / 引用**：Markdown 风格表格、有序无序列表、引用块
- **可测试**：内置前后端一致性测试（tests/）

## 语法速览

| 写法 | 说明 |
|---|---|
| `@title 公文标题` | 大标题，小标宋 2 号居中（`\|` 手工换行） |
| `# 一、` / `## （一）` | 一至四级标题，自动编号 |
| `@to 各单位：` | 主送机关 |
| （无标记行） | 正文，首行缩进 2 字符 |
| `@attach [附件1][附件2]` | 附件说明，自动编号 |
| `@sign 机关署名` / `@date 成文日期` | 落款与日期，右对齐 |
| `@header 发文机关标志` | 红头 | 
| `@cc 抄送：×××` / `@print 印发机关 日期` | 版记 |
| `**加粗**` `*斜体*` `[^1]` `[^1]: 脚注` | 行内格式与脚注 |
| `\| 表头 \| 表头 \|` | 表格 |
| `\@` `\#` 等 | 转义，输出字面字符 |

完整语法见编辑器内「语法」速查面板。

## 快速开始

### 方式一：Web 编辑器（推荐）

前端纯静态（HTML/CSS/JS），导出依赖 PHP + Python：

```bash
# 依赖
pip install python-docx

# 部署：将目录放到任意 PHP 站点下（如 /www/wwwroot/main/gwmd）
# 访问 http://your-host/gwmd/index.php
```

### 方式二：命令行直接转换

```bash
python3 gwmd2docx.py 输入.gwmd 输出.docx
```

## 项目结构

```
gwmd/
├── index.php        # 编辑器页面
├── style.css        # 页面与预览样式
├── app.js           # 前端：GWMD 解析器 + 分页渲染 + 编辑器逻辑（无框架依赖）
├── api.php          # PHP 导出接口（POST 文本 → docx 下载）
├── gwmd2docx.py     # Python 转换核心（python-docx）
└── tests/
    ├── cases.gwmd           # 一致性测试用例
    ├── cases_warnings.gwmd  # 校验提示测试用例
    ├── consistency.py       # 前后端解析一致性对比
    └── pagination/          # 分页模型测试（Node）
```

## 测试

```bash
# 一致性测试：前端 JS 解析结果 vs 后端 Python 解析结果
python3 tests/consistency.py

# 分页模型测试（需 Node.js）
bash tests/pagination/check.sh
```

## 部署说明

- **PHP 接口**（api.php）：接收 POST 文本，调用本地 `gwmd2docx.py` 生成 docx。单次请求体上限 3MB。
- **字体**：导出的 docx 按规范指定字体名称（方正小标宋简体、黑体、楷体、仿宋、宋体、Times New Roman），打开文档的机器需具备相应字体才能正确显示。
- **隐私**：本项目为纯本地工具，文档内容不经过任何第三方服务。
